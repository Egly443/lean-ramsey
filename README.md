# Ramsey theory in Lean 4

A small Lean 4 library of finite Ramsey theory, built on Mathlib's `SimpleGraph.EdgeLabeling`:
Ramsey numbers for any finite number of colours, Ramsey's theorem, graph, induced, ordered,
hypergraph and tournament Ramsey numbers, the Erdős lower bound, and Schur's theorem.

It is a **strawman for the Mathlib community**: a concrete proposal for how this material could
be organised in Mathlib, offered for discussion and review rather than as a finished API.

Builds against a pinned Mathlib commit (see `lakefile.lean`). Licensed under Apache 2.0.
